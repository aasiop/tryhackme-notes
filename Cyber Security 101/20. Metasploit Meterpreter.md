# Metasploit Meterpreter

### Basics

**Meterpreter** - payload within the Metasploit Framework that provides security interactive command shell. Meterpreter runs in memory (RAM) to avoid being detected. Uses encrypted communication to avoid IPS and IDS. Meterpreter will establish TLS communication channel on attacker system  

To get meterpreter process id: `getpid`
> Meterpreter is shows as spoolsv.exe

To find accurate payload: `msfvenom --list payloads | grep meterpreter`

### Meterpreter commands

| Command | Description            |
| ------- | ---------------------- |
| help    | list available command |


**Core commands:**

| Command      | Description                                                                                               |
| ------------ | --------------------------------------------------------------------------------------------------------- |
| `background` | Backgrounds the current session                                                                           |
| `exit`       | Terminate the Meterpreter session                                                                         |
| `guid`       | Get the session GUID (Globally Unique Identifier)                                                         |
| `help`       | Displays the help menu                                                                                    |
| `info`       | Displays information about a Post module                                                                  |
| `irb`        | Opens an interactive Ruby shell on the current session                                                    |
| `load`       | Loads one or more Meterpreter extensions, example: `load python`, and then `python_execute "print 'hey'"` |
| `migrate`    | Allows you to migrate Meterpreter to another process (change of loosing privileges)                       |
| `run`        | Executes a Meterpreter script or Post module                                                              |
| `sessions`   | Quickly switch to another session                                                                         |
| `shell`      | will launch a regular command-line shell on the target system                                             |
