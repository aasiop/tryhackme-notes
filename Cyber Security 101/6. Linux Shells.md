# Linux Shells

---
### Linux shells
Linux has different types of shells available. Bourne Again Shell (Bash) is the default shell for most Linux distributions.
- To see active shell use command: `echo $SHELL`.
- To list available shells: `cat /etc/shells`.
- To switch between shells, simply type shell name.

---
### Shell Scripting

To create shell script use .sh extension, example:
```bash
nano script.sh
```
Start your script with shebang (characters that are added at the beginning of a script, it tells the operating system's kernel which interpreter to execute:
```bash
#!/bin/bash
```

---
### Programming Shell Scripts

>comments start with #

**Variables:**  
Inside a shell script we can use `read` command to take input from user and then use it, example:
```bash
echo "Server name: "
read name
echo "Created $name"
```

You can define variable:
```bash
name="pc1"
echo "Created $name"
```

You can also use variables throughout the terminal session:
```bash
echo "Created $name"
```

**If statements:**  
```bash
echo "Name:"
read name
if [ "$name" = "John" ]; then
	echo "Welcome John"
else
	echo "You are not John!"
fi
```

**Loops:**  
Example loop: (it goes from 1 to 10)
```bash
for i in {1..10};
do
echo $i 
done
```
