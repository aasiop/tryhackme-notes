# IDS Fundamentals

### Basics

**IDS (Intrusion Detection System)** - security tool that monitors networks or computer systems for malicious activity, threats, or policy violations. It records the event and sends an alert to a security team.

---

### Deployment modes

1. **HIDS (Host)**:
	- Installed directly on individual hosts
	- Monitors activity **on that specific host**.
	- Provides detailed host-level visibility.
	- **Disadvantage:** difficult and resource-intensive to manage across large networks.
2. **NIDS (Network)** - 
	- Monitors **network traffic across multiple/all hosts**.

---

### Detection modes

1. **Signature-Based**: (e.g. Snort)
	- Detects threats by matching activity against **known attack signatures** stored in a database
	- Fast and effective against known threats
	- Cannot detect previously unknown/zero-day attacks without an existing signature

2. **Anomaly-Based**:
	- Establishes a baseline of normal behavior
	- Can detect zero-day/previously unknown attacks
	- high false-positive rate

3. **Hybrid**:
	- Combines **signature-based + anomaly-based detection**.

---

### Snort

Snort - open-source IDS solution. Snort modes:

| Mode                | Description                                                                                                                                                                                                                             |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Packet sniffer mode | reads and displays network packets without performing any analysis on them                                                                                                                                                              |
| Packet logging mode | used to detect network traffic in real-time and display the detections as alerts on the console. **Saves all network packets** to disk for storage and future review                                                                    |
| Network IDS         | monitors network traffic in real-time and applies its rule files to identify any match to the known attack patterns stored as signatures. **Analyzes live traffic** against predefined security rules to find threats. **Primary mode** |

### Snort rules

![Rule format.png](rule_format.png)

Creating rules:
```bash
sudo nano /etc/snort/rules/local.rules
```

Add line, example:
```bash
alert icmp any any -> 127.0.0.1 any (msg:"Loopback Ping Detected"; sid:10003; rev:1;)
```

Start Snort:
```bash
sudo snort -q -l /var/log/snort -i lo -A alert_fast -c /etc/snort/snort.lua
```

Test rule (ping on another device):
```
ping 127.0.0.1
```

Key options:
- `-q` → quiet mode
- `-l` → log directory
- `-i` → network interface
- `-A alert_fast` → fast alert output
- `-c` → configuration file

Running snort on PCAP files:
```bash
sudo snort -q -l /var/log/snort -r Task.pcap -A alert_fast -c /etc/snort/snort.lua
```

### Another snort example

 IDS Rule for HTTP traffic inside local.rules:

create rule:
```text
alert tcp any 80 -> any any (msg:”TCP Port 80 Scan”; sid:1000001; rev:1;)
alert tcp any any -> any 80 (msg:”TCP Port 80 Scan”; sid:1000002; rev:1;)
```

>alternative:
>```text
>alert tcp any 80 <> any any (msg:”TCP Port 80 Scan”; sid:1000001; rev:1;)
>```

start snort form pcap file:
```bash
sudo snort -c local.rules -A full -l . -r mx-3.pcap
```

analyse specific number of packets:
```bash
sudo snort -r snort.log.1752506656 -n 63
```
