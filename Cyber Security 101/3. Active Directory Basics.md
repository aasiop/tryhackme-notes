# Active Directory

### Basics:
- Active directory (AD) - directory service used to manage users, computers, and other resources in a Windows Domain.
- Windows Domain - a group of users and computers managed by an organization. It contains AD DS (Active Directory Domain Services)
- Domain Controller (DC) - a server that runs Active Directory services and manages the Windows domain

For better understanding:
```text
WINDOWS DOMAIN
│
├── Active Directory Domain Services (AD DS)
│   │
│   └── Active Directory (AD)
│       ├── Users
│       ├── Machines
│       ├── Groups
│       ├── Policies
│       └── other
│
└── Domain Controllers (DC)
    │
	├── DC01
	│ └── Runs AD DS
	│
	└── DC02
		└── Runs AD DS
```

---
### Active Directory objects:
1. Users -  user accounts that can be authenticated within the domain. They can also be granted permissions to access resources such as files, folders, printers, and other network resources
2. Machines - for every computer that joins the Active Directory domain, a machine object will be created. Each machine account has its own password, which is automatically changed periodically. These passwords are randomly generated and can be up to 120 characters long. Names of machines ends with $.
3. Security groups - used to group users and machines for easier permission management. Groups can also contain other groups. More below:


| Security Group     | Description                                                                                       |
| :----------------- | :------------------------------------------------------------------------------------------------ |
| Domain Admins      | Full administrative access across the domain, including Domain Controllers.                       |
| Server Operators   | Can perform administrative tasks on Domain Controllers but cannot change admin group memberships. |
| Backup Operators   | Can access files for backup/restore operations, ignoring their permissions                        |
| Account Operators  | Can create and modify certain domain accounts.                                                    |
| Domain Users       | Includes all existing user accounts in the domain.                                                |
| Domain Computers   | Includes all existing computers in the domain.                                                    |
| Domain Controllers | Includes all Domain Controller (DC) accounts.                                                     |

---
### Organizational Units (OUs)

Organizational Units (OUs) - container objects that allow you to classify users and machines. They are like folders, but instead of files, they contain network objects.

**Security Groups vs OUs**

- **OUs (Organizational Units)** – used to apply policies and configurations to users and computers based on their role. A user or computer can belong to only one OU at a time.
- **Security Groups** – used to assign permissions to resources, such as shared folders or network printers. A user can be a member of multiple groups.

**OU = “Where does the user/computer belong, and what policies apply to it?”**  
**Security Group = “What does the user have access to?”**

### Default Windows containers

| Container                | Description                                               |
| :----------------------- | :-------------------------------------------------------- |
| Builtin                  | contains default groups available on Windows systems      |
| Computers                | contains any machine joining network                      |
| Domain Controllers       | contains OU that contains DCs in network                  |
| Users                    | contains user accounts and groups                         |
| Managed Service Accounts | contains accounts used by services in the Windows domain. |

### Managing in AD

***To delete OUs and users:***
view -> advanced features
right click on user/ou -> properties -> object -> turn off protect object form accidental deletion

***To delegate (allows to grant users specific privileges to perform advanced tasks on OUs without needing a Domain Administrator to step in):***
right click -> Delegate Control -> add -> give tasks to delegate
