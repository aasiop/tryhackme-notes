# Windows PowerShell

---
## What is PowerShell

Windows PowerShell is a modern, object-oriented scripting language.
**Command Prompt (CMD)** processes inputs and outputs as simple, flat **text strings**, whereas **PowerShell** processes them as rich, structured **.NET objects**, allowing for advanced system automation and scripting. ==It returns objects that retain their properties and methods==

---

## Basics

PowerShell commands are known as ==cmdlets== (command-lets). Here are some basic cmdlets commands:

>Command output can be filtered using `-[CommandInfo] [value]`
>for example Get-Command shows CommandType, Name, Version and Source. We can then filer it with e.g. `Get-Command -CommandType "Function"`

>Commands support wildcard patterns

>adding -examples at the end of commands shows command usage examples

| Command                                                             | Description                                                        |
| ------------------------------------------------------------------- | ------------------------------------------------------------------ |
| Get-Command                                                         | lists all available cmdlets, functions scripts                     |
| Get-Help [command]                                                  | shows help page of command                                         |
| Get-Alias                                                           | lists all aliases available (e.g. cd is an alias for Set-Location) |
| Find-Module -Name "[name]"                                          | Search for modules (collections of cmdlets) in online repositories |
| Install-Module -Name "[name]"                                       | Installs module                                                    |
| Get-ChildItem                                                       | like ls in linux or dir in cmd                                     |
| Set-Location -Path "[path]"                                         | like cd                                                            |
| New-Item -Path "[path\filename]" -ItemType "[type, e.g. directory]" | creates file, file name in path                                    |
| Remove-Item -Path "[path\filename]"                                 | removes both files and directories                                 |
| Copy-Item -Path [path\filename] -Destination [path\filename]        | copy file or move files (MoveItem)                                 |
| Get-Content -Path "[path\filename]"                                 | prints content (like cat in linux)                                 |

### Piping

Piping (`|`) allows the output of one command to be used as the input for another. In PowerSHell piping passes objects rather then text. Piping **examples**:

| Command                                              | Description                                          |
| ---------------------------------------------------- | ---------------------------------------------------- |
| Get-ChildItem \| Sort-Object Length                  | prints content and sorts by **object** Length        |
| ... \| Where-Object -Property "Extension" -eq ".txt" | prints content when extension is .txt                |
| ... \| Where-Object -Property "Name" -like "ship*"   | prints content when object name starts with ship     |
| ... \| Select-Object Name,Length                     | selects the Name and Length properties to be printed |

> Another way to filtering cmdlets is command Select-String. It is similar to grep in Linux or findstr in Windows. Example: `Select-String -Path ".\captain-hat.txt" -Pattern "hat"` - 

| Command | Description  |
| ------- | ------------ |
| -eq     | equal        |
| -gt     | greater than |
| ...     |              |

### System and Network commands

| Command                | Description                                    |
| ---------------------- | ---------------------------------------------- |
| Get-ComputerInfo       | prints advanced system information             |
| Get-LocalUser          | prints all local user accounts on the system   |
| Get-NetIPConfiguration | prints advanced system’s network configuration |
| Get-NetIPAddress       | prints IP addresses details on the system      |
| Get-Process            | like task manager                              |
| Get-Service            | prints services                                |
| Get-NetTCPConnection   | prints TCP connections                         |
#### Other:

| Command                                                                          | Description                         |
| -------------------------------------------------------------------------------- | ----------------------------------- |
| Get-FileHash -Path .\path.txt                                                    | prints file hash                    |
| Get-Item -Path "C:\[path]" -Stream *                                             | prints Alternate Data Streams (ADS) |
| Invoke-Command -FilePath c:\scripts\test.ps1 -ComputerName Server01              | runs script on a server             |
| Invoke-Command -ComputerName [computer_name] -ScriptBlock { [e.g. Get-Service] } | runs script on a remote server      |
