
# REMnux: Getting Started

### Basics

**REMnux** - specialised Linux distro. Provides a sandbox-like environment for dissecting potentially malicious software without risking your primary system

---
### File analysis

`oledump.py` -  Python tool that analyzes **OLE2**/**Compound File Binary Format** files

output explanation:
- **A** → stream/container index.
- **A1, A2, A3...** → individual **data streams**.
- `**M**` → indicates a **macro** stream.
- `VBA/ThisWorkbook` is therefore worth investigating.

Commands:

| Command                                           | Description                    |
| ------------------------------------------------- | ------------------------------ |
| `oledump.py agenttesla.xlsm`                      | performs file analysys         |
| `bash oledump.py agenttesla.xlsm -s 4`            | selects a specific data stream |
| `oledump.py agenttesla.xlsm -s 4 --vbadecompress` | produces readable VBA code     |
