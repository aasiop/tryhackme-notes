# Networking Core Protocols

---

### DNS

DNS (Domain Name System) - maps a domain name to an IP address. Uses port ==**53**==.

**Main DNS Records:**
- **A Record** – maps a hostname to an **IPv4 address**.
- **AAAA Record** – maps a hostname to an **IPv6 address**.
- **CNAME Record** – maps one domain name to another domain name (e.g. example.com, example.org)
- **MX Record** – specifies the mail server responsible for a domain.

> to find a domain's IP address use: `nslookup [site]` command

---
### WHOIS

**whois** - command to look up a domain info (it outputs assigned to domain: name, phone number, email etc.)

---
### HTTP & HTTPS

**HTTP (Hypertext Transfer Protocol)** - used for communication between a web browser and a web server.  Port is ==**80**==.
**HTTPS** is the secure version of HTTP. The **S** stands for **Secure**. Enables encryption. Port is ==**443**==.  

**HTTP Methods:**
- **GET** – retrieves data from the server, e.g. a web page or image.
- **POST** – sends new data to the server, e.g. a form or file.
- **PUT** – creates or updates a resource.
- **DELETE** – deletes a resource.

`telnet` commands can be used to communicate directly with a web server using HTTP, example: `GET / HTTP/1.1`

---

### FTP

FTP (File Transfer Protocol) - used for transferring files. FTP listens on TCP port ==**21**== by default. Usage: `ftp [ip]`.  
Inside ftp we can use commands:
- **ls** - shows list of files available for download
- **type ascii** - switches to ASCII mode
- **get file.txt** - retrieves file
- **quit** - quits ftp

---

### SMTP

**SMTP (Simple Mail Transfer Protocol)** -  defines how a mail client talks with a mail server and how a mail server talks with another. Uses port ==**25**==. Use telnet to communicate.

---

### POP 3

**POP3 (The Post Office Protocol version 3)** - allows the client to communicate with a mail server and retrieve email messages. Uses port ==**110**==. Use telnet to communicate.

---

### IMAP

**IMAP (Internet Message Access Protocol)** - used to synchronize emails across multiple devices. Unlike **POP3**, IMAP keeps emails on the server and synchronizes their status between email clients. Uses port ==**143**==. Use telnet to communicate.
