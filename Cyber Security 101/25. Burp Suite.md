# Burp Suite

### Basics

**Burp Suite** - framework designed to serve as a comprehensive solution for conducting web application penetration testing. Captures and enables manipulation of all the HTTP/HTTPS traffic between a browser and a web server.  

| Tool          | Purpose                                                                                                     |
| ------------- | ----------------------------------------------------------------------------------------------------------- |
| **Proxy**     | Intercepts and modifies HTTP requests/responses                                                             |
| **Repeater**  | Captures, modifies, and resends requests repeatedly; useful for payload testing and finding vulnerabilities |
| **Intruder**  | Sends many requests to an endpoint; commonly used for brute-force and fuzzing                               |
| **Decoder**   | Encodes and decodes captured data or payloads                                                               |
| **Comparer**  | Compares two pieces of data at **word or byte level**                                                       |
| **Sequencer** | Tests the randomness of tokens such as session cookies                                                      |

### Burp Proxy

**Burp Proxy** intercepts and captures traffic between the user and the target web server, allowing requests/responses to be **inspected, modified, forwarded, or dropped**.

| Feature                 | Purpose                                            |
| ----------------------- | -------------------------------------------------- |
| **Forward**             | Sends the intercepted request to the server        |
| **Drop**                | Prevents the request from being sent               |
| **Intercept**           | Holds requests before they reach the target server |
| **HTTP history**        | Stores and displays previous HTTP requests         |
| **WebSockets history**  | Stores and displays WebSocket communication        |

> Requests are still **logged** in history even when interception is turned off.

> For Burp Proxy to work you need to setup FoxyProxy on your web browser (for host name use: 127.0.0.1 - localhost address)

### Burp Browser

**Burp Browser** is a built-in **Chromium browser** pre-configured to use the Burp Proxy. Important options:

| Solution         | Description                                                                                                                                                 |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Smart option** | Run Burp Suite under a **low-privilege user**                                                                                                               |
| **Easy option**  | `Settings → Tools → Burp's browser → Allow Burp's browser to run without a sandbox`. Enabling this option will allow the browser to start without a sandbox |

---
### Scoping

**Scoping** defines which traffic Burp Suite should focus on, reducing unnecessary traffic and making testing easier.

- Go to **Target** → right-click the target → **Add To Scope**.
- Choose **yes** to stop logging traffic that is **out of scope**.
- Check or modify the scope in **Target → Scope settings**.
- Scope can **include or exclude domains/IPs**.

> Disabling out-of-scope logging does **not** stop Burp Proxy from intercepting that traffic.
