# Windows command line

---

#### Commands:

| Command              | Description                                         |
| -------------------- | --------------------------------------------------- |
| set                  | displays current environment variables              |
| ver                  | shows OS version                                    |
| systeminfo           | displays OS system details                          |
| cd                   | displays the current directory                      |
| cd [path]            | changes directory                                   |
| dir                  | shows current files in directory (like ls in linux) |
| dir /a               | shows also hidden files                             |
| dir /s               | shows also files in subdirectories                  |
| mkdir [name]         | creates directory                                   |
| rmdir [name]         | removes an empty directory                          |
| copy [file1] [file2] | copies a file to another location or filename       |
| move [file1] [path]  | moves file                                          |
| del [file]           | deletes file                                        |


---
#### Network commands:

| Command       | Description                                                                                                                                 |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| ipconfig      | shows network configuration                                                                                                                 |
| ipconfig /all | more info (DNS, DHCP)                                                                                                                       |
| ping [site]   | check network connection by sending ICMP packet                                                                                             |
| tracert[site] | traces network route traversed to reach target                                                                                              |
| nslookup      | checks DNS to find IP address or specific DNS records (return domain IP address)                                                            |
| netstat       | shows current network connections and listening ports                                                                                       |
| netstat -abon | shows: all connections and listening ports + programs associated with ports + PID process of connection + uses numerical forms of addresses |
