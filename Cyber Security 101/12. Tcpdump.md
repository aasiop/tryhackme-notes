# Tcpdump

### Tcpdump

**Tcpdump** - is a command-line tool that captures and analyses network traffic in real time. It belongs to libpcap library.

---
### Basic Commands

| Command                | Description                                                                                  |
| ---------------------- | -------------------------------------------------------------------------------------------- |
| tcpdump -i [interface] | Captures packets on a specific network interface  <br>(use: `ip a s` to check for interface) |
| tcpdump -w [file]      | Writes captured packets to a file                                                            |
| tcpdump -r [file]      | Reads captured packets from a file                                                           |
| tcpdump -c [count]     | Captures a specific number of packets                                                        |
| tcpdump -n             | Don’t resolve IP addresses                                                                   |
| tcpdump -nn            | Don’t resolve IP addresses and don’t resolve protocol numbers                                |
| tcpdump -v             | Verbose display; verbosity can be increased with `-vv` and `-vvv`                            |

---
### Filtering Commands

| Command                                      | Description                                                           |
| -------------------------------------------- | --------------------------------------------------------------------- |
| tcpdump host [ip] or tcpdump host [hostname] | Filters packets by IP address or hostname                             |
| tcpdump src host [ip]                        | Filters packets by a specific source host                             |
| tcpdump dst host [ip]                        | Filters packets by a specific destination host                        |
| tcpdump port [port]                          | Filters packets by port number                                        |
| tcpdump src port [port]                      | Filters packets by the specified source port number                   |
| tcpdump dst port [port]                      | Filters packets by the specified destination port number              |
| tcpdump [protocol]                           | Filters packets by protocol; examples include `ip`, `ip6`, and `icmp` |

---

### Packets Display Commands:

| Command     | Description                                        |
| ----------- | -------------------------------------------------- |
| tcpdump -q  | Prints shorter output lines                        |
| tcpdump -e  | Include MAC addresses                              |
| tcpdump -A  | Print packets as ASCII encoding                    |
| tcpdump -xx | Display packets in hexadecimal format              |
| tcpdump -X  | Show packets in both hexadecimal and ASCII formats |

---
### Operators

| Operator | Description          |
| -------- | -------------------- |
| &        | and                  |
| \|       | or                   |
| !        | not (1 -> 0, 0 -> 1) |
| ==       | equal                |
| !=       | not equal            |

---
### Other

**TCP flags** that can be filtered include:
- **SYN** – starts a TCP connection.
- **ACK** – acknowledges received data.
- **FIN** – finishes a TCP connection.
- **RST** – resets a connection.
- **PUSH** – pushes data to the application.
