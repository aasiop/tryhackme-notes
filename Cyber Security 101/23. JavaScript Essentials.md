# JavaScript Essentials

### Basics

**JavaScript (JS)** - is a popular **interpreted** scripting language that allows web developers to add interactive features to websites containing HTML and CSS.  

There are three ways to declare variables:
- var - function scope
- let - block scope
- const - block scope

command example:
```javascript 
   <script>
        function PrintResult(rollNum) {
            alert("Username with roll number " + rollNum + " has passed the exam");
        }

        // prepare an array of roll numbers (data)
        const rollNumbers = [101, 102, 103];

        for (let i = 0; i < 100; i++) {
            PrintResult(rollNumbers[i]);
        }
    </script>
        
```

and another example:
```javascript
console.log("Hello, World!");

let age = 25

if (age >= 18) {
    console.log("You are an adult.");
} else {
    console.log("You are a minor.");
}

function greet(name) {
    console.log("Hello, " + name + "!");
}

greet("Bob");
```

### Dialogue Functions

Gives site alert:

```javascript
alert("HelloTHM")
```

Asks for input and then sends alert:
```javascript
name = prompt("What is your name?");
	alert("Hello " + name);
```

Asks: Are you sure ok/cancel
```javascript
confirm("Are you sure?")
```

Age verification example:
```javascript
 <!DOCTYPE html>
<html lang="en">
<head>
    <title>Age Verification</title>
</head>
<body>
    <h1>Age Verification</h1>
    <p id="message"></p>

    <script>
        age = prompt("What is your age")
        if (age >= 18) {
            document.getElementById("message").innerHTML = "You are an adult.";
        } else {
            document.getElementById("message").innerHTML = "You are a minor.";
        }
    </script>
</body>
</html>
```
