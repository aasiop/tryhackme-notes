# SQL Fundamentals

### Basics

**Database** - an organised collection of structured information or data that is easily accessible and can be manipulated or analysed. Database has different types:
- Relational (SQL) - Stores structured data in tables consisting of rows and columns
- Non-relational (NoSQL) - Stores data in non-tabular formats such as documents, key-value pairs or collections

In relational database there are: tables, rows, columns and keys.

> `mysql -u root -p` runs mysql database

---
### Keys

**Keys** are used to identify records and create relationships between tables:
- **Primary Key** - a column used to **uniquely identify each record** in a table.
- **Foreign Key** - a column that references a column in another table, creating a **relationship between tables**.

---
### Database and Table Statements

Basic database commands:

| Command                            | Description                      |
| ---------------------------------- | -------------------------------- |
| `CREATE DATABASE [database_name];` | creates database                 |
| `SHOW DATABASES;`                  | prints list of present databases |
| `USE [database_name];`             | selects database                 |
| `DROP database [database_name];`   | removes database                 |

Creating table:
```sql
CREATE TABLE example_table_name (
example_column1 data_type,
example_column2 data_type,
example_column3 data_type
);
```

example (with parameters):
```sql
CREATE TABLE book_inventory (
book_id INT AUTO_INCREMENT PRIMARY KEY,
book_name VARCHAR(255) NOT NULL,
publication_date DATE
);
```

|Feature|Description|
|---|---|
|`INT`|Stores integers|
|`AUTO_INCREMENT`|Automatically generates sequential values for new records|
|`PRIMARY KEY`|Uniquely identifies each record|
|`VARCHAR(255)`|Variable-length text with a maximum of 255 characters|
|`NOT NULL`|Prevents the column from containing `NULL` values|
|`DATE`|Stores dates|

Working on tables:

| Command                    | Description                   |
| -------------------------- | ----------------------------- |
| `SHOW TABLES;`             | shows available tables        |
| `DESCRIBE [table_name]`    | gives detailed view of table  |
| `ALTER TABLE [table_name]` | used to make changes in table |
| `DROP TABLE [table_name];` | removes table                 |

### CRUD Operations

**CRUD** stands for **Create, Read, Update, Delete** -  the basic operations for managing data in a database.

| Operation | SQL statement | Purpose |
|---|---|---|
| **Create** | `INSERT INTO` | Adds a new record |
| **Read** | `SELECT` | Retrieves records |
| **Update** | `UPDATE` | Modifies existing records |
| **Delete** | `DELETE` | Removes records |

Examples:
```sql
INSERT INTO books (id, name, published_date, description)
VALUES (1, "Android Security Internals", "2014-10-14", "An In-Depth Guide to Android's Security Architecture");
```

```sql
SELECT * FROM books
```
output: shows everything in table books

```sql
SELECT name, description FROM books;
```
output: shows name and description in table books

```sql
UPDATE books
SET description = "An In-Depth Guide to Android's Security Architecture."
WHERE id = 1;
```

```sql
DELETE FROM books WHERE id = 1;
```

### SQL Clauses

| Clause     | Purpose                                   |
| ---------- | ----------------------------------------- |
| `FROM`     | Specifies the table being accessed        |
| `WHERE`    | Filters records based on a condition      |
| `DISTINCT` | Removes duplicate values                  |
| `GROUP BY` | Groups records with the same value        |
| `ORDER BY` | Sorts results                             |
| `HAVING`   | Filters grouped results after aggregation |
Examples:

| Clause     | Command                                                                              |
| ---------- | ------------------------------------------------------------------------------------ |
| `DISTINCT` | SELECT DISTINCT name FROM books;                                                     |
| `GROUP BY` | SELECT name, COUNT(`*`)  <br>FROM books  <br>GROUP BY name;                          |
| `ORDER BY` | SELECT * FROM books<br>ORDER BY published_date ASC;                                  |
| `HAVING`   | SELECT name, COUNT(`*`)<br>FROM books<br>GROUP BY name<br>HAVING name LIKE '%Hack%'; |

### SQL operators

Logical operators:

|Operator|Purpose|
|---|---|
|`LIKE`|Matches a specific pattern|
|`AND`|Returns `TRUE` if **all** conditions are true|
|`OR`|Returns `TRUE` if **at least one** condition is true|
|`NOT`|Reverses a condition|
|`BETWEEN`|Checks if a value is within a specified range|

examples:
```sql
SELECT * FROM books WHERE description LIKE "%guide%";
SELECT * FROM books WHERE category = "Offensive Security" AND name = "Bug Bounty Bootcamp";
SELECT * FROM books WHERE name LIKE "%Android%" OR name LIKE "%iOS%";
SELECT * FROM books WHERE NOT description LIKE "%guide%";
SELECT * FROM books WHERE id BETWEEN 2 AND 4;
```


### Functions

String functions

|Function|Purpose|
|---|---|
|`CONCAT()`|Combines two or more strings|
|`GROUP_CONCAT()`|Combines values from multiple rows into one string|
|`SUBSTRING()`|Extracts part of a string|
|`LENGTH()`|Returns the number of characters in a string|
examples:
```sql
SELECT CONCAT(name, " is a type of ", category, " book.") AS book_info FROM books;

SELECT category, GROUP_CONCAT(name SEPARATOR ", ") AS books
FROM books
GROUP BY category;

SELECT SUBSTRING(published_date, 1, 4) AS published_year FROM books;

SELECT LENGTH(name) AS name_length FROM books;
```

Aggregate Functions;

| Function  | Purpose                                         |
| --------- | ----------------------------------------------- |
| `COUNT()` | Counts rows                                     |
| `SUM()`   | Calculates the sum of values (excluding `NULL`) |
| `MAX()`   | Returns the maximum value                       |
| `MIN()`   | Returns the minimum value                       |
examples:
```sql
SELECT COUNT(*) AS total_books FROM books;

SELECT SUM(price) AS total_price FROM books;

SELECT MAX(published_date) AS latest_book FROM books;

SELECT MIN(published_date) AS earliest_book FROM books;
```
