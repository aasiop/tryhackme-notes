# Networking Essentials
### DHCP

**DHCP (Dynamic Host Configuration Protocol)** - automatically assigns network settings to devices: IP address subnet mask, default gateway, DNS server.

DHCP follows four steps: Discover, Offer, Request, and Acknowledge (DORA):

1. **DHCP Discover**: The client broadcasts a DHCPDISCOVER message seeking the local DHCP server if one exists.
2. **DHCP Offer**: The server responds with a DHCPOFFER message with an IP address available for the client to accept.
3. **DHCP Request**: The client responds with a DHCPREQUEST message to indicate that it has accepted the offered IP.
4. **DHCP Acknowledge**: The server responds with a DHCPACK message to confirm that the offered IP address is now assigned to this client.

> Client (0.0.0.0) sends DHCP packet to 255.255.255.255 (broadcast) address

### ARP

**ARP (Address Resolution Protocol)** - makes it possible to find the MAC address of another device on the Ethernet.

> two devices on the same Ethernet/Wi-Fi cannot communicate without knowing each other’s MAC addresses

ARP asks for MAC address using broadcast MAC address (ff:ff:ff:ff:ff:ff):
```text
cc:5e:f8:02:21:a7 → ff:ff:ff:ff:ff:ff ARP 42 Who has 192.168.66.1? Tell 192.168.66.89
44:df:65:d8:fe:6c → cc:5e:f8:02:21:a7 ARP 42 192.168.66.1 is at 44:df:65:d8:fe:6c
```

> It is encapsulated within Ethernet frame (remember for wireshark)

### ICMP

**ICMP (Internet Control Message Protocol)** - used for network diagnostics and error reporting. There are 2 popular ICMP commands for troubleshooting:

1. ping - checks connectivity to target system:
	- Sends ICMP Echo Request (ICMP Type 8)
	- Receiver responds with an ICMP Echo Reply (ICMP Type 0).
2. traceroute (tracert on Windows) - discovers route from host to target *(explained in Windows command line)*. It uses the **TTL (Time-to-Live)** field that indicates the maximum number of routers a packet can travel through. Each router decreases the TTL by 1.

### Routing

Routing Protocols: (help routers determine how to deliver packets between different networks):

- **OSPF (Open Shortest Path First):** Routers share network topology information and calculate the most efficient paths.
- **EIGRP (Enhanced Interior Gateway Routing Protocol):** Cisco proprietary protocol that uses factors such as bandwidth and delay to choose efficient routes.
- **BGP (Border Gateway Protocol):** The main routing protocol of the Internet. It exchanges routing information between different networks/ISPs.
- **RIP (Routing Information Protocol):** Simple protocol mainly for small networks. It chooses routes based on the **fewest hops**.

### NAT

**NAT (Network Address Translation)** helps solve the limited number of IPv4 addresses. It allows many ==private IP addresses to share one public IP address== for Internet access.
