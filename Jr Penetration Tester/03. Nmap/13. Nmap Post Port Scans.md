# Nmap Post Port Scans

### Nmap Scripting Engine

**Nmap Scripting Engine (NSE)** - allows Nmap to automate tasks beyond simple port scanning. Scripts are stored in `/usr/share/nmap/scripts`.

Example:
```bash
sudo nmap -sS --script "http-date" 10.201.118.127
```

### Saving output

| Option | Description                                     |
| ------ | ----------------------------------------------- |
| `-oN`  | Save output in normal format (.nmap)            |
| `-oG`  | Save output in a grepable format (.gnmap)       |
| `-oX`  | Save output in XML format                       |
| `-oA`  | Save output in normal, XML and Grepable formats |
