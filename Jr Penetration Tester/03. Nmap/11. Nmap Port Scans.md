# Nmap

### Basics

**Nmap** - network scanning and host discovery tool.

---
### Commands:

| Option    | Description                                                    |
| --------- | -------------------------------------------------------------- |
| -sn       | Discover live hosts                                            |
| -sL       | List targets without scanning                                  |
| -sT       | TCP Connect Scan  <br>(complete three-way handshake)           |
| -sS       | TCP SYN Scan  <br>(only first step of the three-way handshake) |
| -sU       | UDP Scan                                                       |
| -F        | Fast mode – Scan 100 most common ports                         |
| -p[range] | Specify ports to scan                                          |
| -p-       | Scan all ports                                                 |


#### Command examples

| Command                        | Description                                          |
| ------------------------------ | ---------------------------------------------------- |
| nmap -sn 192.168.2.0/24        | discovers live hosts on entire network               |
| nmap -sS -p- 192.168.2.1       | runs TCP SYN scan on all port on specific IP address |
| nmap -sS -p 80,443 192.168.2.1 | ... on 80 and 4443 port                              |
| nmap -sS -p 1-1024 192.168.2.1 | ... on port 1 to 1024                                |

---
### More commands:

| Option | Description                                          |
| ------ | ---------------------------------------------------- |
| -O     | OS detection                                         |
| -sV    | Service and version detection                        |
| -A     | OS detection, version detection, and other additions |
| -Pn    | Scan hosts that appear to be down                    |
| -PR    | arp scan                                             |
| -PE    | icmp scan                                            |

#### Command examples:

| Command                  | Description                                     |
| ------------------------ | ----------------------------------------------- |
| nmap -sS -O 192.168.2.1  | runs TCP SYN scan and detects OS                |
| nmap -sS -sV 192.168.2.1 | runs TCP SYN scan and enables version detection |

### Timing

Nmap allows controlling **scan speed and performance**. Slower scans can help avoid triggering IDS/security solutions.

| Option          | Description                                                                 |
| --------------- | --------------------------------------------------------------------------- |
| T0 (paranoid)   | Very slow (example duration: 10h)                                           |
| T1 (sneaky)     | Slow (27 min)                                                               |
| T2 (polite)     | Slower than default (40 sec)                                                |
| T3 (normal)     | Default (0,15 sec)                                                          |
| T4 (aggressive) | Fast (0,13 sec)                                                             |
| T5 (insane)     | Extremely fast. Risks missing ports or crashing fragile systems (<0,13 sec) |

| Option                                          | Description                                      |
| ----------------------------------------------- | ------------------------------------------------ |
| `--min-rate <number>` and `--max-rate <number>` | Minimum and maximum rate (packets/second)        |
| --host-timeout                                  | Maximum amount of time to wait for a target host |
#### Command examples:

| Command                                         | Description                                      |
| ----------------------------------------------- | ------------------------------------------------ |
| nmap -sS -T4 192.168.2.1                        | runs TCP SYN scan with timing 4                  |

---

### Output

| Option       | Description                                                                                   |
| ------------ | --------------------------------------------------------------------------------------------- |
| -v           | Verbose output, shows more scan progress/details.  <br>Shows real time information about scan |
| -vv or -v2   | Increasing verbosity                                                                          |
| -vvvv or -v4 | Increasing verbosity even more                                                                |
| -d           | debugging                                                                                     |
| --reason     | comment why nmap thinks ports are opened                                                      |

### Saving scan report

| Option     | Description                                           |
| ---------- | ----------------------------------------------------- |
| -oN [file] | saves scan report as normal output                    |
| -oX [file] | ... as XML output                                     |
| -oG [file] | ... as Grepable output (Useful with `grep` and `awk`) |
| -oA [file] | Saves all major formats                               |
