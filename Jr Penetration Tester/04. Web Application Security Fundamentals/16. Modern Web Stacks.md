# Modern Web Stacks

### MERN Stack

**MERN** (MongoDB, Express.js, React, Node.js) - full JavaScript stack commonly found behind modern SaaS platforms.

- Express (port 3000 or 5000)
- MongoDB (27017)

We can check for MERN, example:
```bash
curl -I 10.113.154.247:3000/
```
gives:
```text
HTTP/1.1 200 OK
X-Powered-By: Express
Content-Type: text/html; charset=utf-8
...
```
