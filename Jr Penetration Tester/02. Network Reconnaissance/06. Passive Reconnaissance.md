# Passive Reconnaissance

### Basics

**Passive Reconnaissance** - refers to gathering intelligence from public sources without connecting to the target. No detection risk.

Examples:
- Querying public DNS records from open resolvers
- Reviewing job postings on LinkedIn or company career pages for tech stack hints
- Scanning public GitHub repositories for hardcoded credentials or configuration files.
- Checking exposed devices via search engines like Shodan or Censys

---

### Whois / RDAP

**Whois** - command that gives info about domain. Considered legacy.
**RDAP** - uses HTTPS and returns structured JSON.
Example:
```bash
user@TryHackMe$ curl -s https://tryhackme.com | jq .
{
	"domain": "tryhackme.com",
	"handle": "2282723194_DOMAIN_COM-VRSN",
...
```

What to look for:
- Redirection chain (Verisign to registrar server)
- Dates: useful for estimating company age or identifying renewal phishing windows
- Name servers: potential new targets (if in scope)
- Status: locked domains (e.g., `clientTransferProhibited`) are harder to hijack

---

### nslookup / dig

**nslookup** - used to query DNS records (usage: `nslookup DOMAIN_NAME`). You can use specific type to filer out, Example:
```bash
user@TryHackMe$ nslookup -type=MX tryhackme.com 1.1.1.1
Server: 1.1.1.1
Address: 1.1.1.1#53

Non-authoritative answer:
...
```

**dig** - the same but also provides cleaner output and displays TTL values. Example of usage:
```bash
user@TryHackMe$ dig @1.1.1.1 tryhackme.com MX

; <<>> DiG 9.18.28-0ubuntu0.22.04.1-Ubuntu <<>> @1.1.1.1 tryhackme.com MX
; (1 server found)
...
```

---

### DNSDumpster

DNSDumpster - online tool (`dnsdumpster.com`) same like nslookup and dig but also includes subdomains and hosts. Doesn't provide detailed DNS response information like dig.

---

### Shodan.io

**Shodan** - (`https://www.shodan.io`) search engine for internet-connected devices. Unlike Google, which indexes web pages, Shodan focuses on devices: servers, IoT equipment, cameras, routers, industrial control systems, and more.

---

## TLDR

Use `dnsdumpster.com` and `shodan.io`
