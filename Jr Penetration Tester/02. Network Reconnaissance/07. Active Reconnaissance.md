# Active Reconnaissance

### Basics

**Active Reconnaissance** - involves making direct contact by visiting websites, pinging hosts, tracing routes, and connecting to ports. This can reveal live services, open ports, banners, and network paths, but it leaves footprints.

---

### Web Browser

1. **Developer tools** - set of web authoring and debugging tools built directly into modern web browsers Press: **"Ctrl + Shift + I"** to open.
2. **Browser Extensions** - FoxyProxy (BurpSuite), Wappalyzer (identifies technologies used on the site)

---

### Ping

**Ping** - checks internet connection with target (sends a small test packet to a remote host and waits for a reply).

Usage: (-c how many packets)
```bash
ping -c 5 tryhackme.com
```
or
```bash
ping6 tryhackme.com
```

|Result|Most likely meaning|Next step|
|---|---|---|
|Fast replies, low or no packet loss|Target is online and allows ICMP|Proceed to port scanning|
|"Destination Host Unreachable"|Target is down or no route exists|Check if machine is powered on|
|100% packet loss with no error message|ICMP is filtered or blocked|Try TCP/UDP host discovery with Nmap|
|High latency or heavy loss|Network congestion, long distance, or filtering|Investigate the path with `traceroute`|

---

### Traceroute

**Traceroute** - traces the route that packets take from your system to a target host. Sends UDP as default. For TCP use: `-T`. For ICMP mode: `-I`.

Usage:
```bash
traceroute tryhackme.com
```

---

### Telnet, SSH

**Telnet, SSH** - used for remote connection. Telnet is obsolete (sends data in plaintext).

---

### Netcat

**Netcat (nc)** - another remote connection tool. Useful for banner grabbing, port probing, simple file transfers, and basic client-server communication.

Example:
a) Connect
```bash
pentester@TryHackMe$ nc 10.113.168.178 80
GET / HTTP/1.1
host: netcat

HTTP/1.1 200 OK  
Server: nginx/1.6.2  
Date: Tue, 17 Aug 2021 11:39:49 GMT  
...
```

|Option|Meaning|
|---|---|
|`-l`|Listen mode|
|`-p`|Specify the port number|
|`-n`|Numeric only; no DNS resolution of hostnames|
|`-v`|Verbose output, useful for debugging|
|`-vv`|Very verbose output|
|`-k`|Keep listening after the client disconnects|:
b) Listen for connection
```bash
nc -vnlp 1234
```

### TLDR

These tools are useful but the best practise is to use Nmap
