# Cyber Kill Chain

### Basics

**Cyber Kill Chain** - cyber security framework. Helps organisations defend against cyber attacks by understanding how they are conducted. Cyber Kill Chain divides an attack into seven stages:

1. **Reconnaissance**: target information gathering
2. **Weaponisation**: creating a deliverable payload based on found vulnerabilities
3. **Delivery**: sending payload to the target
4. **Exploitation**: payload exploits a vulnerability in the target’s system
5. **Installation**: installing a backdoor or malware to maintain access to target system
6. **Command & Control (C2)**: control system using the installed backdoor
7. **Actions on Objectives**: further actions such as data exfiltration or other systems’ exploitation

---

### Reconnaissance

|Passive Reconnaissance|Active Reconnaissance|
|---|---|
|No direct interaction with the target|Direct interaction with the target|
|WHOIS, DNS records, OSINT|Port scanning, vulnerability scanning|
|Social media, Google Dorking|Social engineering, physical reconnaissance|
|Generally less detectable|Can generate detectable activity|

**Countermeasures:**
- Minimise publicly exposed information
- Use WHOIS privacy protection
- Monitor network traffic and logs for scanning activity

---

### Weaponisation

**Techniques:**

- Ready-made, modified, or custom exploits
- **Exploit kits** — automated platforms containing exploits for multiple vulnerabilities
- Malicious Office macros, executables, or documents
- **Obfuscation/encryption** to evade detection

**Countermeasures:**
- Disable unnecessary software and browser plugins
- Disable Office macros or allow only signed, trusted macros

---
### Delivery

**Common methods:**
- **Phishing** — malicious attachments or links
- **Spear phishing** — targeted, personalised phishing
- **Smishing** — phishing through SMS
- Malicious websites and file-sharing platforms
- **Malvertising** — malicious advertisements
- Social engineering and infected USB drives

**Countermeasures:**
- User awareness training
- Email and web filtering
- WAF, network monitoring, and patch management

---
### Exploitation

**Examples:**

- Weak/default passwords or stolen credentials
- SQL injection and buffer overflow
- Software vulnerabilities
- **Zero-day exploit** — exploit for a vulnerability unknown to the vendor

**Countermeasures:**
- Strong password policies and **MFA**
- Patch management and vulnerability scanning
- **IPS** to block exploitation attempts
- **WAF** to protect against web attacks such as SQL injection, XSS, and CSRF

---
### Installation

**Techniques:**

- Windows scheduled tasks or Linux cron jobs
- Startup script modifications
- Malicious services or daemons
- Backdoors, rootkits, and malware
- **LOLBins (Living-off-the-Land Binaries)** — legitimate system tools abused for malicious purposes
- **Web shells** — scripts allowing remote command execution through a web interface

**Countermeasures:**
- **EDR** to detect suspicious endpoint behaviour
- Monitor newly created processes, services, and accounts
- Regular system audits and secure baseline comparisons
- **Application allowlisting** to restrict unauthorised programs

---
### Command and Control (C2)

**Techniques:**

- Common protocols: **HTTP, HTTPS, DNS, SMTP**
- Encrypted communication to conceal activity
- **DNS tunnelling** — encoding data within DNS requests
- Legitimate cloud services and social media for communication

|Technique|How it works|
|---|---|
|**DGA (Domain Generation Algorithm)**|Generates many domain names; malware searches for an active C2 domain|
|**Fast Flux**|Frequently changes the IP addresses associated with one domain|

**Countermeasures:**
- Firewalls, IDS, and IPS
- Monitor suspicious DNS queries, especially unusually long queries or high request volumes.
- Monitor unusual network traffic and connections to malicious IPs
- Web filtering, HTTPS inspection, and honeypots

> **Remember:** DGA = **many domains**; Fast Flux = **many changing IP addresses**.

---

### Actions on Objectives

**Examples:**

- **Data exfiltration** — stealing sensitive information
- **Ransomware** — encrypting files for financial gain
- Data destruction or service disruption
- Financial theft and espionage
- **Lateral movement** — compromising additional systems within the network
- Manipulating Industrial Control Systems (ICS)

**Countermeasures:**
- **DLP (Data Loss Prevention)** to prevent unauthorised data exfiltration
- Reliable backups and recovery plans
- Network segmentation to restrict lateral movement
- Least privilege and strict access controls
- EDR and user activity monitoring
